# Gundam Mobile App Frontend Project

This is the mobile app frontend project which reads and renders the Gundam Backend Database (explained before in the backend project).

# Getting Started

The easiest way to run the frontend app is using the following expo command:

```bash
cd frontend
npm install
npm start
```

This command installs all the dependencies and keep the project running in an expo server. Then the terminal will show several ways to interact with the mobile app

```bash
› Using Expo Go
› Press s │ switch to development build

› Press a │ open Android
› Press w │ open web

› Press j │ open debugger
› Press r │ reload app
› Press m │ toggle menu
› shift+m │ more tools
› Press o │ open project code in your editor

› Press ? │ show all commands
```

I recommend to use web (w) option to try the app UI. Otherwise you can download the [expo application](https://expo.dev/) in your mobile device (Android or MacOS) and then you can scan the QR code that appears in the terminal output.
